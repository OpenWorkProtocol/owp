# ERC-8004 alignment (informative)

Checked against ERC-8004 on 2026-08-21:
https://eips.ethereum.org/EIPS/eip-8004

ERC-8004 defines Identity, Reputation, and Validation registries for agents.
OWP may reference those records as trust inputs or publish references to
validator evidence through compatible registry flows.

OWP deliberately does not define one universal quality/reputation score. A
strong historical reputation never substitutes for verification of the current
Attempt's exact contract, source snapshot, result commit/tree, and evidence.

The relationship is:

`identity/reputation -> provider selection context`

`OWP execution commitment -> current Attempt identity`

`independent validator attestation -> current delivery validity`
