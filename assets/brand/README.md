# Open Work Protocol brand assets

The master mark is [`owp-mark.svg`](owp-mark.svg). It uses `currentColor` for
interface integration. Fixed black and white versions are provided for
documents and production artwork.

## Included variants

- `owp-mark.svg` — transparent, color-inheriting master mark
- `owp-mark-black.svg` / `owp-mark-white.svg` — fixed one-color marks
- `owp-icon-black.svg` — white mark on a black rounded tile
- `owp-icon-white.svg` — black mark on a white rounded tile
- `owp-icon-black-square.svg` / `owp-icon-white-square.svg` — hard-edged tiles
- `owp-social-dark.svg` / `owp-social-light.svg` — 1280×640 social artwork
- `png/` — raster exports for avatars, icons, and social previews

## Usage

- Preserve the SVG aspect ratio and do not rearrange individual nodes.
- Keep the upper-right terminal open; its negative space is part of the mark.
- Use the black tile where the surrounding background is unknown.
- Use the square exports where the destination applies its own corner mask.
- Use the transparent black or white mark only where contrast is controlled.
- Allow clear space at least equal to one filled-node diameter around the mark.
